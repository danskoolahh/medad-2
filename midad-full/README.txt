مداد Midad — النموذج الأولي
===========================

site/
  index.html, styles.css, app.js   الموقع كاملًا. افتح index.html للبدء.
  بقية ملفات .html                  صفحة لكل ميزة، تفتح الموقع مباشرة على تلك الصفحة
                                    بمستخدم تجريبي مسجّل الدخول (طالب أو ولي أمر أو معلم).
  كل الصفحات تعمل من app.js و styles.css نفسيهما، فأبقِ الملفات في المجلد نفسه.

images/       الرسومات المستخدمة في الموقع، بصيغتي SVG و PNG.
screenshots/  صورة لكل صفحة.

ملاحظات
- الخطوط تُحمّل من Google Fonts، وتحتاج اتصالًا بالإنترنت.
- كل البيانات تجريبية، ولا يُرسل الموقع أي بيانات.
- بوابة الإدارة مشفّرة داخل app.js، وعنوانها ورمزها غير موجودين في الملفات.

Midad prototype
- site/: the full website. Open index.html to start. Every other .html file opens one page directly, signed in as a demo user. Keep all files in the same folder.
- images/: the illustrations used on the site, as SVG and PNG.
- screenshots/: one screenshot per page.
